SMART ROOM VOICE CONTROL
========================

1. Abre una terminal dentro de esta carpeta.
2. Ejecuta: python3 -m http.server 8000
3. Abre Chromium/Chrome y visita: http://localhost:8000
4. Permite el micrófono si el navegador lo solicita.
5. Si el reconocimiento de voz no está disponible, usa el cuadro "Prueba manual".

Archivos:
- index.html: estructura
- styles.css: aspecto visual
- app.js: lógica y reconocimiento de voz
